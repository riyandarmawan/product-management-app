# Toko - Aplikasi Manajemen Produk

Aplikasi berbasis desktop untuk mengelola inventaris produk makanan dan minuman (mencatat, melihat, mengedit, dan menghapus data).

## Prerequisites

* Java Development Kit (JDK)
* NetBeans IDE

## Cara Menjalankan Project

1. **Clone project:** `https://github.com/riyandarmawan/product-management-app.git`
2. **Buka NetBeans IDE**
3. **Open project:** Pilih **File** > **Open Project...**, arahkan ke folder project, lalu klik **Open Project**.
4. **Jalankan Program:** Klik kanan pada project `Toko` dan pilih **Run**.

## Fitur Utama

* **Daftar Produk:** Tabel kode, nama, kategori, dan harga.
* **Pencarian & Filter:** Cari produk berdasarkan nama dan kategori.
* **Tambah Produk:** Input data baru beserta gambar produk.
* **Detail & Aksi:** Melihat detail produk, *Edit*, *Reset*, atau *Hapus*.
